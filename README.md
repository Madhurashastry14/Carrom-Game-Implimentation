# 🎯 Carrom Game

A 2-player Carrom game developed as a **Skill Lab Team Project** by a team of 4 members.

</div>

---

## 📖 About The Project

This project focuses on building an interactive digital Carrom game using frontend technologies.
The current version includes the game interface, gameplay mechanics, striker controls, and collision handling.

Backend functionalities such as authentication, multiplayer synchronization, database integration, and user management are planned for future development.

---

## ✨ Features

- 🎮 2 Player Gameplay
- 🖥️ Interactive and Responsive UI
- 🎯 Smooth Striker Controls
- 💥 Coin Collision Mechanics
- 🕳️ Pocket Detection System
- ⚡ Dynamic Gameplay Experience
